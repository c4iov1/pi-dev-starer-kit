# Issue Tracker

Issues live as markdown files under `.scratch/<feature-slug>/`.

## Format

Each issue file:
```markdown
# NNN — Title

**Status**: <triage-label>
**Type**: AFK | HITL

## What to build
...

## Acceptance criteria
- [ ] ...

## Blocked by
- #NNN (or "None — can start immediately")
```
