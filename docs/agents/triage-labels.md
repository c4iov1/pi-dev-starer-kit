# Triage Labels

Canonical defaults used across this project's issue tracker.

| Label | Meaning |
|---|---|
| `needs-triage` | New issue, not yet evaluated |
| `needs-info` | Waiting on reporter for clarification |
| `ready-for-agent` | Scoped and ready for an AFK agent to implement |
| `ready-for-human` | Requires human decision or intervention |
| `wontfix` | Evaluated and intentionally not fixed |

These labels are recorded as `Status:` lines in issue files under `.scratch/`.
