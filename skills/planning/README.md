# Planning Skills

Use these before or during design work to shape requirements, test assumptions, and break work into implementation slices.

- `plan-mode` — structured planning for complex tasks.
- `grill-me` — stress-test a plan through focused questioning.
- `grill-with-docs` — challenge a plan against `CONTEXT.md` and ADRs.
- `to-prd` — turn conversation context into a PRD.
- `to-issues` — split a PRD or plan into implementation issues.
- `zoom-out` — step back for high-level architecture review.
- `design-an-interface` — explore multiple API/interface designs.
