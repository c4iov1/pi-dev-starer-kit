# Quality Skills

Use these to verify correctness, diagnose failures, review changes, and improve maintainability.

- `self-verify` — run build/test/fix loops before declaring done.
- `review-matrix` — independent correctness/security/maintainability review passes.
- `tdd` — red-green-refactor development workflow.
- `diagnose` — disciplined debugging for bugs and regressions.
- `improve-codebase-architecture` — find deep refactoring opportunities.
- `structural-refactor` — use AST/LSP tools for safe refactors.
