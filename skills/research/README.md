# Research Skills

Use these when the agent needs outside information, browser verification, external services, or parallel investigation.

- `web-research` — search and fetch current web documentation.
- `browser-testing` — automate UI/browser checks and screenshots.
- `mcp-orchestration` — discover and call MCP-connected services.
- `subagent-delegation` — delegate scouting, review, or parallel work to sub-agents.
